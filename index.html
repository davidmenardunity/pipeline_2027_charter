Opening Unity production beyond a single seat of the Editor, for every person, tool, and agent on the team.

The Problem

Every interaction goes through one door

Producers, artists, designers, external partners, automated systems, and AI agents all need to work on the same production. Today the Unity Editor is the main entry point for all of them, and its workflows were never designed for that.

the bottleneck: workflows designed for one persona, used by all of them

Expertise - most roles can't get value out of the Editor Onboarding - adding a collaborator is daunting Licenses - managers restrict Editor seats to control cost
Why this hurts the business

In a macro-environment with constrained funding, this creates a negative perception about the value and cost of a Unity license. Many team members can't get valuable results out of the Editor, onboarding an internal or external collaborator takes daunting effort, and teams have limited ability to automate or extend tooling that scales reliably in production. The result: pipeline managers conservatively restrict the number of Editor licenses assigned across the team.

What Is It

A contract between people, software, agents, and data

Unity Pipeline is a set of APIs and tools that decouple production from the Editor, so studios can build their entire pipeline, from A to Z, for everyone on the team.

interactions defined by a contract, on web, desktop, mobile, or fully automated

Under the hood: the Project Service

The Project Service is a backend implementation, not a customer-facing component. When a new asset is added to a workbench, it creates an on-demand Content File for that asset on the target platform, in seconds.

Packages and services
  • CLI and pipeline package: com.unity.pipeline
  • Project API: Workbench API to interface with your version control system, and the Project Service producing artifacts for all assets in a workbench
  • Collaboration: service plus com.unity.cloud.collaboration for annotations in and outside the Editor
  • Deep linking: service plus com.unity.cloud.deep-linking and com.unity.cloud.authentication
  • Build Accelerator: a cache that speeds up build times

The Ecosystem

Pipeline apps and context-aware links

A Pipeline app is any tool that implements Pipeline APIs: web, desktop, mobile, editor-integrated, or automated. A Pipeline link is an app-independent URL that lets teams move between apps without losing context.

1P

First-party

Built and distributed by Unity. User seat entitlement, subscription plus consumption billing.

2P

Built by a customer for their own needs, on our APIs.

What It Unlocks

Example workflows

Creative asset iteration

Artists modify assets and verify them immediately in-game, on target devices.

QA and live validation

Testers receive live updates on device to verify fixes and integration.

Agentic automation

Developers delegate tasks to AI agents, from rare device bugs to parallel work across branches.

Real-time co-editing

Team members and agents work on the same branch, seeing each other's changes live.

Playtest and stakeholder review

Playable links for remote testing, with in-context feedback.

Build and release management

Content updates as independent artifacts: rollbacks and drops without rebuilding the player.

Three more workflows
  • Custom pipeline development: second and third-party developers build specialized tools on Pipeline APIs, such as prefab-diff tools, custom level editors, or game balancing dashboards.
  • Cross-platform performance analysis: technical artists run scenes across multiple target devices simultaneously and compare metrics against previous revisions.
  • Governance and access control: producers manage project health, monitor branch status, and invite contractors with scoped access, without an Editor seat.

Roadmap

From beta to an open content platform

Q3 2026, Sept

Checkpoint

Public sign-up, private beta. Workbench API, web dashboard, CLI, asset artifacts in seconds.

Details

Use caseScene Preview, aka Beautiful Corner. A producer reviews an outsourced submission in the web dashboard and attaches feedback; the collaborator logs in with scoped access, uploads a fix, and verifies it on device.

  • Web dashboard: Scene Preview workflow, 2D asset thumbnails, asset preview in a generic viewer, annotations, asset search, What's New.
  • Pipeline API and CLI: Workbench API without conflict resolution, asset metadata, asset artifact retrieval, Unity CLI in beta, Editor collaboration package.
  • Under the hood: Project Service generates asset artifacts in seconds, with multi-repo support and project-level RBAC.

Public sign-up, private beta · Free, with simulated pricing shown · Production-supported, API versioned · 6.0 LTS, 6.3 LTS, 6.6

Q4 2026, Unite Tokyo

General Availability

Managed sales. Active billing, CLI release, packages released, Perforce support.

Details

Use caseContinuous Validation. Checkpoints across the asset lifecycle let each persona verify quality in their own tool: an artist checks polycount from Blender before upload, then the asset in-game with Scene Review; QA receives live content updates in a development build.

  • Commercial release: active billing with per-org spend limits, and the Unity CLI out of beta.
  • Unity Editor and dashboard: deep linking, collaboration and pipeline packages released; Perforce support in the web dashboard.
  • Pipeline API: Workbench API merge, Accelerator v2 in beta, Project Service degrades gracefully on unsupported platforms.

Managed sales only · Included in the Editor subscription with credits, plus Creator seat, PAYG and top-up bundles · 6.0 LTS, 6.3 LTS, 6.7 LTS

Q1 2027, GDC

Public self-serve

Available to everyone, including Personal edition. Play Scene in the browser.

Details

Use casePlay Scene (ideation). An artist selects a scene in the web dashboard and clicks Play to start playing right there, seeing their asset updates in the project. QA plays individual scenes or the entire game in the browser. Example demo: a scene diff tool.

  • Web dashboard: Play Scene in the browser.
  • Pipeline API: scene artifact generation, Accelerator v2 out of beta.
  • Project Service: additional platform support.

Public, self-serve, including Personal edition · Pricing as at GA · Scope beyond the above is TBD

Q2 to Q3 2027

Enterprise-ready

Self-hosted deployment, privacy and security for protected IP, Live Authoring API and Editor Authoring SDK in beta.

Details

Use caseLive multi-user authoring (ideation), the Figma of Unity. People sharing a workbench see each other's modifications, cursors and cameras in real time in the Editor; second and third parties can build the same into their own apps.

  • Self-hosted deployment, so studios with protected IP keep control of their data.
  • Live Authoring API and Editor Authoring SDK, both in beta.
  • Moby integration for the shared asset library.

Public self-serve plus self-hosted deployment · License-based model for self-deployment, TBD · Scope beyond the above is TBD

  • Live Authoring API out of beta, with Unity Studio integration.
  • Third-party commercialization of Pipeline apps.

The Problem

Every interaction goes through one door

Producers, artists, designers, external partners, automated systems, and AI agents all need to work on the same production. Today the Unity Editor is the main entry point for all of them, and its workflows were never designed for that.

the bottleneck: workflows designed for one persona, used by all of them

Expertise - most roles can't get value out of the Editor Onboarding - adding a collaborator is daunting Licenses - managers restrict Editor seats to control cost
Why this hurts the business

In a macro-environment with constrained funding, this creates a negative perception about the value and cost of a Unity license. Many team members can't get valuable results out of the Editor, onboarding an internal or external collaborator takes daunting effort, teams have limited ability to automate or extend tooling that scales reliably in production, and AI agents cannot work concurrently alongside humans or each other. The result: pipeline managers conservatively restrict the number of Editor licenses assigned across the team, or seek alternatives to Unity that are friendlier to agentic workflows.

What Is It

A contract between people, software, agents, and data

Unity Pipeline is a set of APIs and tools that decouple production from the Editor, so studios can build their entire pipeline, from A to Z, for everyone on the team.

interactions defined by a contract, on web, desktop, mobile, or fully automated

The Project Service

Accessed through the Project API, the Project Service is a process that creates artifacts, like Content Files, for an asset on a target platform, so it can be loaded in a Unity runtime. On demand, in seconds.

It is a process, so it can run locally or as a service in the cloud, behind the Project API. When a new asset is added to a workbench, the Project Service creates an on-demand Content File for it on the target platform.

The Ecosystem

Pipeline apps and context-aware links

A Pipeline app is any tool that implements Pipeline APIs: web, desktop, mobile, editor-integrated, or automated. A Pipeline link is an app-independent URL that lets teams move between apps without losing context.

1P

First-party

Built and distributed by Unity, by other teams on these same APIs: Studio, CoCreate, Spark, the Hub. User seat entitlement, subscription plus consumption billing.

2P

Second-party

Built by a customer for their own needs, on our APIs.

3P

Third-party

Built by a customer and monetized outside their organization.

The API layer serves two profiles
  • Enterprise professionals: experienced studios already running productions in the traditional Unity ecosystem.
  • New, top-of-funnel creators: people building Unity projects whose entry point is a simpler authoring app — Spark, CoCreate, Studio — rather than the Editor. Today 800k people a month download the Hub and never install the Editor; a first-party Pipeline app is how they get in.

Both profiles reach the same project through the same contract, which is why first-party apps built by other Unity teams and customer-built apps are not separate ecosystems.

What It Unlocks

Example workflows

Because the Unity Editor is no longer a bottleneck, creation becomes a fluid handoff between AI, human collaborators, and custom tools.

An agent reaches the Pipeline API to generate a blocked-out level and initial scripts, with no download or setup time. A game designer jumps into a lightweight web tool to review and tweak that level in the browser. A technical artist opens the exact same project state in the full Editor to finalize lighting and performance.

Creative asset iteration

Artists, audio designers and narrative designers modify assets in their own tools, and verify the change immediately in-game on target devices.

QA and live validation

QA and automated systems test builds on devices, receiving live updates from developers to verify bug fixes and integration.

Agentic automation

Developers delegate complex tasks to AI agents, such as investigating rare device bugs, or executing parallel tasks across branches without conflicts.

Real-time co-editing

Multiple team members and agents — an environment artist and a designer, say — work simultaneously on the same project branch, seeing each other's changes in real time.

Playtest and stakeholder review

Game designers and producers distribute playable links for remote testing, letting stakeholders review work and leave feedback in context.

Build and release management

Release engineers deploy content updates as independent artifacts, enabling rollbacks and content drops without rebuilding or redistributing the player binary.

Custom apps

Second and third-party developers build specialized, domain-specific “Editors” or web tools on Pipeline APIs: prefab-diff tools, custom level editors, game balancing dashboards.

Cross-platform performance

A technical artist runs the same scene across several target devices at once and compares performance against a previous revision.

Governance and access control

Producers manage project health, monitor branch status, and invite contractors with scoped access, all without needing an Editor seat.
